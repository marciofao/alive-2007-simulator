# Alive 2007 — simulador de palco

Simulador interativo em um único arquivo HTML, inspirado no palco da turnê Alive 2007.

## Abrir


- Demo online: [abrir a demonstração interativa]https://marciofao.github.io/alive-2007-simulator/).


## Controles de teclado

| Atalho | Ação |
| --- | --- |
| `1` / `2` / `3` / `4` | Selecionar luzes da esquerda / direita / base ou a grade central |
| `←` / `→` | Ajustar o ângulo das luzes ou o matiz da grade central |
| `↑` / `↓` | Ajustar intensidade das luzes ou dos contornos da grade |
| `[` / `]` | Trocar a cor do grupo selecionado |
| `H` / `G` | Girar o matiz do fundo e do grupo selecionado para frente / para trás |
| `M` | Alternar entre cones de luz e pontos |
| `Q` | Ocultar ou mostrar a barra lateral |
| `F` / `Esc` | Entrar em tela cheia / sair |
| `B` | Ligar ou desligar o estrobo do fundo |
| `+` / `−` | Ajustar a velocidade do estrobo |
| `T` | Ligar ou desligar a alternância automática do matiz dos contornos |
| `K` / `L` | Diminuir ou aumentar a velocidade da alternância |
| `,` / `.` | Diminuir ou aumentar a intensidade dos contornos |
| `Espaço` | Pausar ou retomar a animação |
| `?` | Mostrar ou ocultar a legenda |
| `Tab` | Navegar pelos controles; `Enter` carrega o link do YouTube |

O estrobo pode causar desconforto ou crises em pessoas fotossensíveis; use o controle para desligá-lo quando necessário. A reprodução do YouTube requer conexão com a internet.
